# Research Method

The working loop is evidence-first.

```text
current referent
    ↓
observe exact state
    ↓
record evidence
    ↓
state the required relation
    ↓
form the smallest hypothesis
    ↓
test against existing evidence
    ↓
contradiction? → reject / revise
    ↓
predict or construct next valid movement
    ↓
observe the result
    ↓
compare prediction : observation
    ↓
preserve what survived
    ↓
continue
```

## Layer rule

```text
language
  → math one layer up
  → implementation
```

Implementation is downstream of the relation being claimed.

If implementation exposes a contradiction, return to the smallest unsupported relation rather than adding machinery to conceal it.

## Promotion rule

A useful observation does not become a permanent rule merely because it worked once.

Promotion requires a stable witness contract, surviving counterexamples, and a clear statement of what the result does not establish.

## Provenance rule

Whenever a later movement depends on earlier evidence, enough ancestry must remain reachable to inspect why that movement was admitted.

Compression is allowed.

Untraceable invention is not.
